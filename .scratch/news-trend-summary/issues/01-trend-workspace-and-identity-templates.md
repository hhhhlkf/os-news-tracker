# 01 — 趋势总结工作台与身份模板

**What to build:** 用户可在“统计与发现”的趋势总结模块中新建、选择或删除身份模板，并保存全局日期窗口、趋势数 X、候选目标 G、定时规则和当前定时模板；没有趋势结果时也能看到清晰的空状态与四步流程。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

**Module boundary:** 新增前后端代码分别放在 `backend/app/trends/` 与 `frontend/src/features/trends/`；既有页面仅作为入口和容器，不承载模板、设置或运行状态业务逻辑。

- [ ] 身份模板可创建、选择和删除，身份文本限制为 300 字且创建后不可编辑。
- [ ] 全局日期窗口、X、G 和定时配置可保存并在重新打开页面后恢复；G 默认 20。
- [ ] 页面显示新闻卡片生成、聚类、故事线生成、趋势总结四步的未开始状态。
