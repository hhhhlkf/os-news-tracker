# 03 — 新闻解释卡生成与重试

**What to build:** 已入库新闻可异步生成五字段中文解释卡，并在趋势任务开始前补齐缺失卡片；用户可从工作台看到新闻卡片阶段的执行或失败状态。

**Blocked by:** 01 — 趋势总结工作台与身份模板.

**Status:** ready-for-agent

**Module boundary:** 解释卡 Prompt、生成任务、状态和数据访问均归 `backend/app/trends/`；既有新闻入库链路只允许触发其公开接口，不承载卡片逻辑。

- [ ] 每张解释卡保存新闻主角、动作、结果、后续影响、形成原因、业务日期和当前生成版本；卡片列表复用新闻流已有的中文标题 `items.title_tldr`，缺失时回退原始标题。
- [ ] 卡片内容使用中文，关键技术短语和缩写保留原文；只依据新闻标题和正文。
- [ ] LLM 输出必须通过结构校验；失败时最多重试三次，最终失败不写入卡片并保留可重试状态。
- [ ] 结果、后续影响、形成原因缺少原文依据时统一保存为“无”；事件核心向量拼接时舍弃这些“无”字段，卡片 Prompt 与向量版本随规则同步升级。
- [ ] 工作台的新闻卡片列表使用中文状态与字段名，每页 3 条并提供页码；新闻标题与 `YYYY-MM-DD` 业务日期同一行，卡片紧凑展示。
