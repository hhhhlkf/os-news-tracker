# 04 — 版本化向量索引与候选簇生成

**What to build:** 已生成解释卡可按统一版本生成事件核心向量、检索相近卡片并形成可审查候选簇；尚未成线的单卡进入待匹配生命周期。

**Blocked by:** 02 — Embedding 接入预检与版本状态; 03 — 新闻解释卡生成与重试.

**Status:** ready-for-agent

**Module boundary:** 向量索引、候选生成、聚类参数与待匹配生命周期均归 `backend/app/trends/`，不得写入现有新闻筛选或智能探查模块。

- [ ] 事件核心向量包含主角、动作、结果、形成原因和后续影响，并记录模型/向量版本。
- [ ] 聚类按全局 G、严格连接、动态阈值与最大簇容量产生不超过 `3G` 的候选簇。
- [ ] 无法成簇的卡片进入 90 天待匹配状态，候选簇生成过程在工作台可见。
