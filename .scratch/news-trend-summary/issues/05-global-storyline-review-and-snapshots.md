# 05 — 全局故事线审查与渐进更新

**What to build:** 系统可由 Agent 审查候选簇，形成全局持续演进的故事线、成员关系和快照，并正确处理近重复、合并、拆分、归档与重新激活。

**Blocked by:** 04 — 版本化向量索引与候选簇生成.

**Status:** ready-for-agent

**Module boundary:** 故事线、成员、快照和 Agent 审查编排由 `backend/app/trends/` 独立拥有；其他模块只能通过趋势服务查询结果。

- [ ] Agent 可接受、拆分、移除或拒绝候选簇；只有至少两条非重复证据的结果成为故事线。
- [ ] 成员关系保存为核心、支持或近重复；近重复可展示但不增加影响力和窗口交集。
- [ ] 故事线保存总体与窗口日期/分数、成员、聚类信息和极简快照；最近 90 天活跃故事线可自动续接，归档故事线只能经 Agent 确认重新激活。
