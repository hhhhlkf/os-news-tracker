# 06 — 模板趋势评估、窗口评分与发布

**What to build:** 用户可手动运行选定身份模板；系统基于当前日期窗口的故事线生成中文趋势结论，并只在完整成功后发布该模板的最新结果。

**Blocked by:** 01 — 趋势总结工作台与身份模板; 05 — 全局故事线审查与渐进更新.

**Status:** ready-for-agent

**Module boundary:** 模板评估、发布原子性、趋势结果与运行状态均归 `backend/app/trends/`；不得复用或改写既有 Digest 任务实现。

- [ ] 运行按窗口内的非重复成员回填故事线和趋势结果的窗口日期、窗口影响力与排序分，同时保留总体值。
- [ ] Agent 仅对前 `3X` 候选按身份生成相关性、类别、中文主题、中文总结和审查说明；无法验证的变化不占 X。
- [ ] JSON 失败最多重试三次；失败、取消或不完整结果不替换最近成功结果，流程图能显示复用、执行和失败状态。
