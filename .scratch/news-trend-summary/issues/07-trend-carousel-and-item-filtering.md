# 07 — 趋势轮播与新闻精确筛选联动

**What to build:** 选中模板后，技术新闻追踪页在搜索框上方展示其当前窗口内的趋势轮播；用户可从趋势或单条来源直接精确过滤新闻列表。

**Blocked by:** 06 — 模板趋势评估、窗口评分与发布.

**Status:** ready-for-agent

**Module boundary:** 轮播、流程和设置组件放在 `frontend/src/features/trends/`；技术新闻追踪页仅挂载组件并接收其 `item_id` 筛选回调。

- [ ] 双栏轮播展示前 X 条可验证趋势、中文类别标签、主题、总结和来源胶囊；无可验证趋势时展示空状态。
- [ ] 点击趋势卡按全部引用新闻筛选；点击来源胶囊会填入标题文本并以单个新闻 ID 精确筛选。
- [ ] 清除筛选后新闻列表恢复原状态；同名新闻不会因标题模糊匹配而误命中。
