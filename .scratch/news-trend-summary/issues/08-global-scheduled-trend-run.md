# 08 — 全局定时趋势任务

**What to build:** 系统按照唯一的全局定时规则，为当前定时模板自动运行趋势总结，并安全复用或补齐事实层，避免并发重复运行。

**Blocked by:** 06 — 模板趋势评估、窗口评分与发布.

**Status:** ready-for-agent

**Module boundary:** 全局趋势定时规则和执行编排归 `backend/app/trends/`；现有 scheduler 仅注册趋势模块的公开启动入口，不得承载趋势业务判断。

- [ ] 定时任务按保存的频率、执行时刻和当前定时模板触发，使用当时的全局日期窗口、X 与 G。
- [ ] 事实层未完成时先补齐或复用；同一模板已有运行时不重复创建任务。
- [ ] 成功、失败、跳过和复用状态可在趋势工作台查看，且不会覆盖最近成功的轮播结果。
