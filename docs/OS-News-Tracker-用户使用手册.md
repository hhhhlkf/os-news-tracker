# News Tracker（OS新闻追踪）系统使用手册

> **文档用途：** 帮助普通用户和系统管理员使用 OS News Tracker 查询技术新闻、发现站点、管理爬取方式、发送邮件及查看统计数据。
>
> **适用对象：** 新闻阅读用户、信息运营人员、系统管理员。
>
> **文档版本：** V1.0
>
> **更新日期：** 2026 年 7 月

---

## 新手快速上手

第一次使用时，先根据自己的目标选择下面的功能。普通用户可以直接浏览新闻、订阅邮件和使用智能探查；“系统定时抓取”需要先在页面右上角输入管理密码。

| 我想做什么 | 最简单的操作方法 | 详细说明 |
| --- | --- | --- |
| 浏览新闻 | 进入顶部“新闻流” → 输入关键词或选择筛选条件 → 单击新闻卡片查看详情 → 单击“阅读原文”查看原始内容 | [查看“新闻浏览”说明](#3-新闻流) |
| 订阅或发送邮件 | 先在“新闻流”筛选需要的新闻 → 打开“邮件任务中心” → 立即发送，或保存模板并创建每日/每周预定任务 | [查看“邮件订阅”说明](#4-邮件任务中心) |
| 探查新的新闻来源 | 进入顶部“站点发现” → 设置时间范围和条目数量 → 输入网站、公众号或关键词 → 启动智能探查 → 等待系统生成候选爬取方式 | [查看“智能探查”说明](#62-智能探查网站) |
| 设置自动抓取 | 先使用管理密码登录 → 返回“新闻流” → 打开“系统定时抓取” → 设置执行时间、频率和回看范围 → 启用任务 | [查看“系统定时抓取”说明](#5-系统定时抓取) |

### 第一次使用建议

1. 先进入[新闻流](#3-新闻流)，熟悉搜索、筛选和新闻详情；
2. 需要定期接收新闻时，再配置[邮件订阅](#4-邮件任务中心)；
3. 系统没有收录目标网站时，使用[智能探查](#62-智能探查网站)新增来源；
4. 管理员确认爬取方式可用后，再开启[系统定时抓取](#5-系统定时抓取)。

> **权限提示：** 新闻浏览、邮件订阅和智能探查可直接使用；系统定时抓取及其他管理功能需要先完成[管理登录](#2-访问系统与管理登录)。

## 1. 系统简介

OS News Tracker 是一个面向操作系统、Linux 发行版、开源基础设施、安全动态及 AI 工具链的技术新闻情报平台。

用户可以通过系统完成以下工作：

- 浏览和搜索技术新闻；
- 按分类、重要度、热点、时间和来源筛选新闻；
- 查看新闻摘要、技术要点和推荐理由；
- 将当前筛选结果生成邮件并发送；
- 使用智能探查发现新网站的新闻抓取方式；
- 运行和管理已保存的爬取方式；
- 配置系统定时抓取任务；
- 查看查询、站点探查和新闻入库统计。
### 主要功能列表

| 功能模块 | 主要功能 | 使用权限 |
| --- | --- | --- |
| 新闻浏览 | 浏览新闻列表、翻页和查看新闻详情 | 普通用户 |
| 新闻搜索与筛选 | 按关键词、主分类、重要度、技术热点、时间和查询来源筛选新闻 | 普通用户 |
| 智能推荐 | 查看系统自动生成的新闻推荐理由 | 普通用户 |
| 邮件订阅 | 将当前新闻筛选结果生成 HTML 预览并发送邮件 | 普通用户 |
| 智能探查 | 探查网页、微信搜索、微信公众号和司内论坛等信息来源 | 普通用户 |
| 爬取方式库 | 查看、选择和运行已保存的爬取方式 | 普通用户 |
| 主分类维护 | 新增、改名或删除没有关联新闻的空分类 | 普通用户 |
| 审核预选处理方式 | 批量审核、删除候选爬取方式及设置审核提醒 | 管理员 |
| 爬取方式管理 | 删除爬取方式和执行管理操作 | 管理员 |
| 系统定时抓取 | 配置定时任务、立即执行、停止任务和查看运行明细 | 管理员 |
| 微信认证 | 续期微信公众号查询功能（必须登陆才能使用相关功能） | 管理员 |
| 统计与发现 | 查看 Token 消耗、任务明细、趋势和每日消息量 | 管理员 |

系统顶部提供三个主入口：

| 页面 | 主要用途 | 是否需要管理权限 |

| 站点发现 | 智能探查网站、查看和运行爬取方式 | 探查和运行不需要；审核及高级配置需要 |
| 统计与发现 | 查看 Token 消耗、任务统计和每日消息量 | 需要 |

## 3. 新闻流

“新闻流”是系统首页，用于浏览、搜索和筛选已入库的技术新闻。

![\[图片\]](<img/image copy 4.png>)

### 3.1 页面信息

页面顶部显示以下概览信息：

### 3.2 搜索新闻

在搜索框中输入关键词，可搜索新闻标题、摘要和分类。

### 3.3 筛选新闻

系统支持以下筛选条件：

- 主分类：按新闻所属主题分类筛选；
- 重要度：按高、中、低重要度筛选；
- 技术热点：按具体技术标签筛选；
- 发布时间：可选择最近 24 小时、7 天、30 天或自定义日期；
- 查询时间：按新闻进入系统的时间筛选；
- 查询链接：按具体抓取来源筛选。
启用筛选后，页面会显示当前筛选标签。单击“清空筛选”可恢复全部新闻。

> **注意**
>
- 多个筛选条件会同时生效；
- 筛选结果为空时，可减少筛选条件或更换关键词；
- 只有当前处于启用状态的抓取来源才会出现在“查询链接”筛选项中。

### 3.4 排序与翻页

新闻列表支持以下排序方式：

- 发布时间：最新优先；
- 发布时间：最早优先；
- 入库时间：最新优先；
- 入库时间：最早优先。
每页显示 10 条新闻。使用列表下方的“上一页”和“下一页”切换页面。

### 3.5 查看新闻卡片

每张新闻卡片通常包含：

- 重要度；
- 信息类型和主分类；
- 日期；
- 新闻标题或一句话短标题；
- 推荐理由。
单击新闻卡片可打开详情面板。

### 3.6 查看新闻详情

详情面板可展示：

- 完整标题和摘要；
- 来源链接；
- 技术要点；
- 分类、标签和重要度；
单击“阅读原文”可打开新闻来源页面。阅读完成后，单击页面遮罩可退出详情。
推荐理由显示在新闻卡片中，并由系统自动生成。生成期间卡片会显示“正在生成推荐理由”。

## 4. 邮件任务中心

邮件任务中心用于将新闻查询结果生成邮件，可立即发送，也可保存为模板或设置定时发送。
邮件内容以打开任务中心时的新闻筛选条件为准。建议先在新闻流中完成搜索和筛选，再进入邮件任务中心。

### 4.1 打开邮件任务中心

1. 在新闻流设置所需筛选条件；
2. 查看“当前筛选”是否正确；
3. 单击“打开邮件任务中心”。
任务中心会显示模板数量、预定任务数量及启用中的预定任务数量。

#### 功能配图

![\[图片\]](<img/image copy 6.png>)

### 4.2 立即发送

**操作步骤：**

1. 进入“立即发送”；
2. 确认当前筛选条件；
3. 填写收件人和邮件标题；
4. 生成 HTML 邮件预览；
5. 检查预计纳入的新闻条目；
6. 确认内容无误后发送。
**发送前应重点检查：**

- 收件人地址是否正确；
- 新闻时间范围是否正确；
- 新闻数量是否符合预期；
- 邮件标题是否清楚；
- HTML 预览是否完整。
### 4.3 保存邮件模板

如果同类邮件需要重复发送，可将当前配置保存为模板。

**模板通常保存以下内容：**

- 模板名称；
- 邮件标题；
- 固定收件人；
- 新闻筛选条件；
- 邮件展示配置。
保存后，可在“模板列表”中查看、预览、修改或删除模板。模板详情可修改模板名称、邮件标题和收件人；如需修改新闻筛选条件，应返回“立即发送”，按新条件重新保存模板。
### 4.4 创建预定发送

可从邮件模板创建每日或每周发送任务。

**操作步骤：**

1. 在模板列表中选择模板；
2. 单击“创建预定发送”；
3. 设置任务名；
4. 选择每日或每周；
5. 设置发送时间；
6. 检查收件人和筛选条件；
7. 保存并启用任务。
所有定时时间均按北京时间（UTC+8）判定和展示。

**预定任务支持：**

- 暂停；
- 恢复；
- 修改时间与频率；
- 查看最近发送结果；
- 查看发送日志；
- 删除任务。
> **提示：** 保存的时间筛选是筛选快照。最近 24 小时、7 天、30 天等相对时间，会在每次发送时按当时的时间重新计算。

## 5. 系统定时抓取

系统定时抓取用于按计划批量运行当前启用中的爬取方式，并将获取的新闻写入新闻流。
此功能需要先完成管理登录。
单条爬取方式失败不会阻断整批任务。只有全部方式成功，状态才会显示“今日已完成”。
### 5.1 配置定时任务

**管理员可设置：**

- 是否启用定时抓取；
- 每日执行时间；
- 执行频率；
- 新闻回看时间范围；
- 巡检间隔。
所有时间按北京时间（UTC+8）展示。
### 5.2 查看运行明细

**运行记录中可查看：**

- 任务开始和结束时间；
- 已执行的爬取方式；
- 每个方式的成功或失败状态；
- 新增入库数量；
- 失败原因；
- 结构化运行日志。
如果状态为“部分成功”或“执行失败”，应优先查看失败方式及错误信息。

## 6. 站点发现

“站点发现”用于让 AI 分析网站、搜索页或微信公众号入口，生成可重复使用的爬取方式。
### 6.1 设置抓取限制

页面顶部的“抓取限制”统一控制本页运行任务的范围，包括——抓取时间窗口，总条目数上限。
这些限制会用于方式库批量抓取、标准抓取和相关查询任务。开始操作前应先检查限制，避免抓取范围过大或结果过少。
### 6.2 智能探查网站

**操作步骤：**

1. 进入“站点发现”；
2. 设置抓取限制；
3. 在智能探查区域输入网站或目标入口；
4. 按页面要求补充来源名称、来源类型或探测备注；
5. 启动智能探查；
6. 查看探查流程、节点状态和实时日志；
7. 等待探查完成。
探查完成后，系统会生成候选爬取方式。新生成的方式通常先进入“待审核方式”，审核通过后才进入正式爬取方式库。

系统支持自动推断，也可根据目标主动选择网页、微信搜索、微信公众号或司内论坛等类型。对于需要重新分析的相同目标，可按页面提示执行覆盖重探。

**探查过程中可查看：**

- 当前执行阶段；
- 各节点输入和输出摘要；
- 生成的抓取规则；
- 失败节点及错误原因；
- 实时运行日志。
运行过程中可以取消探查；探查失败后，可查看错误并重试。自动命名失败不会改变目标地址，可稍后再次尝试。

候选方式的样例条目、质量评分和审计原因应在后续“待审核方式”或方式详情中查看；Token 消耗统一在“统计与发现”页面查看。

### 6.3 待审核方式

待审核方式只对已完成管理登录的用户显示。
待审核列表支持多选或全选后批量通过、批量删除。管理员还可设置审核提醒开关、提醒间隔和管理员邮箱，并立即发送一次提醒。
### 6.4 爬取方式库

爬取方式库展示系统已保存的抓取方法。用户可查看，来源名称和来源类型。

**常用操作：**

- 选择一个或多个方式运行；
- 取消正在执行的批次；
批量运行时，系统按顺序抓取已选择的方式。结果会进入新闻流和运行日志。
方式库支持分页。运行期间页面可能显示“运行中”或“取消中”；完成后会显示成功或失败。返回页面后可查看最新状态，并按需重新运行失败或已取消的方式。

### 6.5 主分类

“主分类修改”区域用于查看和维护系统当前使用的新闻主分类，可新增分类或修改名称。只有没有关联新闻条目的空分类可以删除。
如果操作被系统拒绝，请先完成管理登录后重试。修改分类前应确认不会影响现有筛选习惯和邮件模板中的筛选条件。

### 6.6 Prompt 工作室

Prompt 工作室是管理功能，用于调整抓取过程中各处理阶段使用的提示词套餐。
一般如果不想对主题有太大改动，用户无需操作。

### 6.7 微信认证

微信公众号相关查询需要有效的微信扫码会话。
会话过期后，微信公众号查询可能失败。完成扫码或续期后，新的登录状态会用于下一次公众号查询。

## 7. 统计与发现

“统计与发现”页面用于查看系统查询、智能探查和新闻入库情况。由于页面包含系统 Token 用量，必须先完成管理登录。

### 7.1 选择统计时间

选择时间范围后，页面中的指标、图表和明细会同步更新。
查询统计还可按“定时/巡检”或“手动查询”筛选。

### 7.2 查看统计图表

**系统提供以下图表：**

- 每次探查 Token：查看每次站点探查的输入和输出消耗；
- 每次查询 Token：查看单次查询任务中各爬取方式的消耗；
- 时间段 Token 趋势：查看一段时间内输入和输出 Token 的变化；
- 每日消息量：按高、中、低重要性查看每日入库新闻数量。

将鼠标悬停在图表上，可查看具体任务、时间和数值。

### 7.4 查看任务明细

**页面底部提供：**

- 查询任务明细；
- 探查任务明细。

可结合任务时间、触发类型、爬取方式和 Token 总量定位消耗较高的任务。

## 8. 推荐使用流程

### 8.1 日常阅读新闻

1. 打开“新闻流”；
2. 选择最近 24 小时或最近 7 天；
3. 按主分类、重要度或热点筛选；
4. 查看新闻摘要和技术要点；
5. 对重要内容打开原文进一步阅读。

### 8.2 制作并发送专题邮件

1. 在新闻流输入专题关键词；
2. 设置时间、分类、重要度和来源；
3. 检查筛选结果；
4. 打开邮件任务中心；
5. 生成 HTML 预览；
6. 确认收件人后发送；
7. 如需重复发送，将配置保存为模板或预定任务。

### 8.3 新增网站抓取方式

1. 进入“站点发现”；
2. 设置合理的时间窗口和条目上限；
3. 输入目标网站并启动智能探查；
4. 查看样例条目和质量结果；
5. 管理员审核新方式；
6. 审核通过后，在爬取方式库手动运行；
7. 返回新闻流检查入库结果；
8. 确认稳定后纳入系统定时抓取。

### 8.4 每日运营检查

1. 管理登录；
2. 打开系统定时抓取，检查今日状态；
3. 如有失败，查看失败方式和日志；
4. 在新闻流检查今日新增内容；
5. 在统计与发现中检查消息量和 Token 消耗；
6. 检查邮件预定任务最近发送结果。

## 9. 常见问题

### 9.1 页面显示演示数据

**原因：** 页面未能连接系统数据服务。

**处理建议：**

1. 刷新页面；
2. 确认网络连接正常；
3. 确认访问地址正确；
4. 联系管理员检查系统服务。

### 9.2 搜索或筛选后没有新闻

**处理建议：**

1. 缩短关键词；
2. 清除部分分类或重要度筛选；
3. 扩大时间范围；
4. 单击“清空筛选”重新查询。

### 9.3 管理功能没有显示

**原因：** 尚未登录、登录状态失效或密码错误。

**处理建议：** 在页面右上角重新输入管理密码，确认显示“管理已解锁”。

### 9.4 新闻原文打不开

**可能原因：**

- 来源网站暂时不可用；
- 原始链接已经失效；
- 当前网络无法访问该网站。

可稍后重试，或联系管理员检查来源链接。

### 9.5 智能探查失败

**处理建议：**

1. 检查网址是否完整；
2. 确认网站可从当前网络访问；
3. 查看失败节点和运行日志；
4. 减少抓取条目上限后重试；
5. 涉及微信公众号时，检查微信认证是否有效；
6. 将错误信息提供给管理员。

探查流程图中通常使用绿色表示已完成、蓝色表示进行中、灰色表示待执行、红色表示失败，可据此快速定位失败阶段。

### 9.6 爬取任务显示部分成功

说明批次中至少有一个方式失败，但其他方式已经完成。打开运行明细，查看失败方式和失败原因即可，无需重新运行全部成功方式。

### 9.7 定时邮件没有发送

**检查以下内容：**

1. 预定任务是否启用；
2. 发送时间和频率是否正确；
3. 收件人是否有效；
4. 关联模板是否存在；
5. 最近发送结果是否显示失败；
6. 发送通道是否正常。

### 9.8 统计页面无法访问

统计页面需要管理权限。请先在页面顶部使用管理密码登录。

### 9.9 微信公众号查询失败

进入“站点发现”的微信认证区域，检查扫码会话是否存在或已过期。必要时重新扫码或续期。

## 10. 使用注意事项

- 不要将管理密码转发给无关人员；
- 删除爬取方式、邮件模板或预定任务前，应确认不再使用；
- 执行大范围抓取前，先设置时间窗口和条目上限；
- 新爬取方式应先检查样例和质量结果，再审核通过；
- 邮件正式发送前，必须检查收件人、标题和 HTML 预览；
- 修改 Prompt 套餐后，应先进行小范围探查验证；
- 发现持续失败、数据异常或大量无关内容时，应保存任务时间和错误信息并联系管理员。

## 11. 问题反馈信息

向管理员反馈问题时，建议提供：

- 问题发生时间；
- 所在页面；
- 执行的具体操作；
- 页面显示的状态或错误信息；
- 相关网站、爬取方式或任务名称；
- 问题截图；
- 是否可以稳定复现。
