### 4. Agent Crawl UI 功能
- 取消按钮（`POST /crawl-sources/{id}/runs/{run_id}/cancel`）
- 删除按钮（`DELETE /crawl-sources/{id}`，含完整 FK 级联清理）

**删除的 FK 级联顺序（均无 ON DELETE CASCADE）：**
```
item_tags, item_entities, item_sources(item_id维度), user_item_scores, user_item_interactions
→ items (source_id维度)
→ item_sources (source_id维度)
→ agent_crawl_runs
→ source (agent_source_configs + agent_site_memory 有 CASCADE 自动清)
```

**竞争条件修复：** 删除前先 flush 运行中 run 为 failed，前端 500 时自动等 1.5s 重试
