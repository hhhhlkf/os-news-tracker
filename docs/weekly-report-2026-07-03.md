## 一、本周概要

本周围绕「采集能力扩展」与「订阅分发闭环」推进，主要完成微信多源探查、邮件任务中心、系统定时晨抓，以及发现工作台侧的方式库筛选、Prompt 自定义与主分类自定义。平台从「能抓、能看」进一步走向「可配置采集 + 可订阅推送」。

---

## 二、新增功能

### 1. 新增爬取方式：微信搜索 & 微信公众号查取

智能探查（Discovery）支持将输入路由到微信相关采集路径：

- **微信搜索**：按关键词检索微信文章，支持分页抓取、限流/验证码感知，以及文章正文补抓。
- **微信公众号查取**：基于公众号账号解析与历史文章拉取，补齐公众号侧内容来源。

与原有网站探查一并纳入多路由发现流程，生成可复用的 crawl method，进入「爬取方式库」统一管理与执行。

**价值：** 覆盖站外微信生态内容，补齐 OS / 安全 / 社区类情报中常见的公众号与搜一搜来源。

---

### 2. 邮件订阅功能

首页接入 **邮件任务中心**，形成「筛选 → 预览 → 发送 / 定时」闭环，主要包括：

| 能力 | 说明 |
|------|------|
| 邮件发送 | 基于当前首页筛选条件生成 HTML 简报预览，支持立即发送；通道支持 TOF4 API 与 SMTP |
| 模版设置 | 保存筛选快照、收件人、邮件标题等为模板，可复用；相对时间（如近 24h / 7d）发送时动态求值 |
| 群组 / 预定设置 | 支持预定发送列表；模板与预定任务复用主页筛选语义，便于按群组或固定条件定期投递 |

**价值：** 用户无需每天打开控制台，即可按既定筛选条件收到情报简报。

---

### 3. 定时爬取（系统晨抓）

新增 **系统晨抓配置与执行窗口**，按配置的时间间隔 / 周期对「爬取方式库」中已启用的 discovery methods 自动执行抓取：

- 支持晨抓配置、立即执行、停止执行
- 提供今日状态、运行时间线、失败方式明细
- 调度与巡检日志写入统一日志流

说明：定时爬取业务主模型面向 discovery 爬取方式库，不再依赖旧 sources 调度作为主路径。

**价值：** 采集从手动触发升级为可周期运行，保证情报库持续更新。

---

### 4. 订阅源（爬取方式）选中与筛选

「抓取模块 · 爬取方式库」增强批量操作与列表能力：

- 支持多选后 **抓取选中** / 批量删除
- 支持列表筛选、分页与状态管理，便于从大量方式中定位目标源

**价值：** 大规模方式库下可精准挑选要跑的源，降低误操作与无效抓取成本。

---

### 5. Prompt 自定义（Prompt 工作室）

新增 **Prompt 工作室**，管理 discovery / enrich 相关 prompt 套餐：

- 支持启用、停用
- 支持自定义覆盖，便于按站点或场景调整筛选与抽取策略

**价值：** 探查失败或筛选不准时，可优先通过澄清 / 调整 prompt 边界改进效果，减少硬编码特例。

---

### 6. 主分类自定义

新增 **主分类修改** 能力：

- 维护富集阶段可用的主分类列表
- 变更同步影响条目分类与首页 / 邮件侧的主分类筛选与订阅

**价值：** 可按业务大类（如 OS 性能、安全、兼容性等）组织订阅与筛选，贴近实际情报消费习惯。
